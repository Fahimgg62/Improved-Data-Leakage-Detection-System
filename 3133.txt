Project Title: Improved Data Leakage Detection System



1. INTRODUCTION

Improved Data Leakage Detection System is a web-based system designed to provide organizations with a secure and accountable method for sharing confidential files among authorized users. The system combines standard file-sharing functionality with a file-tracking mechanism that allows organizations to identify the recipient-specific copy associated with a leaked file.

In conventional file-sharing systems, an administrator may know who was given access to a document, but it can be difficult to determine which recipient's copy was responsible for a subsequent leak. The proposed system addresses this limitation by generating recipient-specific copies of sensitive files and embedding unique dummy or decoy data into those copies.

When a suspected leaked file is recovered, an authorized administrator can upload it to the system for analysis. By comparing the dummy data contained in the leaked file with the recipient-specific records maintained by the system, the system can identify the copy from which the leak is likely to have originated.

The system is intended to support organizations such as software companies, corporate offices, universities, examination departments, medical institutions, and research laboratories where unauthorized disclosure of confidential information can cause significant damage.


1.1 PURPOSE

The purpose of the Improved Data Leakage Detection System is to provide a secure platform for uploading, storing, sharing, monitoring, and investigating confidential files.

The main objectives of the system are:

1. To provide authorized users with secure access to organizational files.
2. To allow administrators to upload and distribute confidential documents.
3. To generate recipient-specific copies of sensitive files.
4. To insert unique dummy or decoy information into distributed copies for traceability.
5. To maintain records of file distribution and recipient information.
6. To allow administrators to upload suspected leaked files for investigation.
7. To compare leaked files with stored tracking information.
8. To identify the recipient-specific copy associated with a suspected leak.
9. To maintain an audit trail of relevant file-sharing activities.
10. To reduce the risk and impact of unauthorized disclosure of confidential information.

The system is intended to provide traceability and investigation support. It should not be considered as automatic or conclusive proof that a particular employee intentionally committed a data leak.

1.3 INTENDED USE

The Improved Data Leakage Detection System is intended to be used by organizations that need to distribute confidential information to multiple authorized users while maintaining the ability to investigate potential data leaks.

A typical usage scenario is described below:

1. An administrator logs into the portal using authorized credentials.

2. The administrator uploads a confidential file to the system.

3. The administrator selects one or more authorized employees as recipients.

4. The system generates a recipient-specific version of the file.

5. Unique dummy or decoy data is inserted into each recipient's copy where applicable.

6. The recipient receives or downloads the assigned file.

7. The system records relevant sharing and access information.

8. If the confidential information is later suspected to have been leaked, the administrator obtains the suspected leaked file.

9. The administrator uploads the leaked file to the investigation module.

10. The system analyzes the leaked file and compares its tracking information with the stored recipient records.

11. The system reports the matching recipient-specific copy and relevant tracking information to assist the administrator's investigation.

The system should only be used by authorized personnel. It is not intended to replace organizational security policies, access-control mechanisms, employee monitoring policies, or legal investigation procedures.


1.4 PRODUCT SCOPE

The scope of the Improved Data Leakage Detection System includes the design and development of a secure web-based platform for controlled file distribution and leak traceability.

IN SCOPE

The system will provide the following major functionalities:

1. User registration and authentication.

2. Role-based access control for administrators and employees.

3. Secure login and logout.

4. File upload and secure storage.

5. File sharing between authorized users.

6. Recipient-specific file generation.

7. Insertion and management of unique dummy or decoy data.

8. File download and access tracking.

9. File-sharing history and audit logs.

10. Management of users and shared files by administrators.

11. Uploading suspected leaked files for investigation.

12. Automated comparison of leaked files with recipient-specific tracking data.

13. Identification of the likely source copy of a leaked file.

14. Display of investigation results to authorized administrators.

15. Basic security controls to prevent unauthorized access to files and tracking information.


OUT OF SCOPE

The following features are outside the primary scope of the proposed system:

1. Automatic prevention of users from photographing or manually copying displayed information.

2. Guaranteed identification of the person who physically leaked a file.

3. Monitoring of users' personal devices outside the system.

4. Investigation of leaks occurring entirely outside the organization's technical infrastructure.

5. Legal or disciplinary decisions against suspected employees.

6. Protection against every possible method of data exfiltration.

The system primarily provides controlled file distribution, traceability, and evidence to support leak investigation.


1.5 RISK DEFINITIONS

The following risks are considered relevant to the Improved Data Leakage Detection System:

1. UNAUTHORIZED ACCESS

Description:
An unauthorized person gains access to the portal or confidential files.

Impact:High


2. CREDENTIAL COMPROMISE

Description:
A user's username or password is obtained or misused by another person.

Impact:High


3. DATA LEAKAGE

Description:
Confidential information is copied, shared, or distributed without authorization.

Impact:Critical


4. TRACKING DATA MANIPULATION

Description:
Tracking information or dummy-data records are modified, deleted, or manipulated by an unauthorized user.

Impact:High


5. FALSE ATTRIBUTION

Description:
A leaked file matches a recipient's copy, but the actual person responsible for the leak cannot be conclusively established.

Impact:High


6. FILE CORRUPTION

Description:
A file becomes corrupted during uploading, processing, storage, or downloading.

Impact:Medium


7. SYSTEM FAILURE

Description:
Server, database, or application failure prevents users from accessing files or performing investigations.

Impact:High


8. PRIVACY RISK

Description:
Sensitive user or organizational information is exposed because of improper system access or inadequate security controls.

Impact:High


9. MALICIOUS INSIDER

Description:
An authorized user intentionally attempts to leak confidential information or bypass system security controls.

Impact:Critical


10. TRACKING EVASION

Description:
A user modifies, converts, or transforms a file in a way that removes or alters the embedded tracking information.

Impact:High


RISK MANAGEMENT

The system should implement appropriate security measures, authentication mechanisms, authorization controls, input validation, encryption, logging, monitoring, and data-protection techniques to reduce the identified risks.

The tracking mechanism should be treated as an investigative aid. A match between a leaked file and a recipient-specific copy should not automatically be considered conclusive proof of intentional wrongdoing. Further investigation may be required before taking administrative, organizational, or legal action.
